> **Mandatory Workflow**:
> 1. Read `brain/AGENT_RULES.md` and `brain/CONTEXT_HANDOFF.md`.
> 2. Read `brain/CURRENT_STATUS.md` and relevant domain files before touching any code.
> 3. Verify all assumptions against live source code.
> 4. Make minimal, surgical code changes. Never alter existing business rules or UI without explicit instructions.
> 5. **Git Policy is MANUAL ONLY**: Never stage, commit, push, reset, or modify Git branches.
> 6. Update the Universal Brain immediately after finishing any task.
